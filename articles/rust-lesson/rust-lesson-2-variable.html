Rust 第二课：变量与可变性

一、学习目标

完成本课后，你应该能够：

  • 理解 Rust 变量的概念与作用。
  • 使用 let 声明变量。
  • 理解变量默认不可变的特性。
  • 使用 mut 声明可变变量并修改变量的值。
  • 理解 Rust 的静态类型系统与类型推断。
  • 使用类型标注显式指定变量的数据类型。
  • 理解 Shadowing（变量遮蔽）的原理与用法。
  • 区分变量遮蔽与可变变量的区别。
  • 理解代码块与变量作用域。
  • 使用 const 声明常量。
  • 掌握 Rust 变量、常量的基本命名规范。

二、变量是什么？

变量（Variable）是程序用来存储数据的名称。程序运行时，可以通过变量保存数字、文字、布尔值等信息，并在后续代码中使用它们。

例如，我们可以声明一个年龄变量：

fn main() {
    let age = 24;
    println!("Age: {}", age);
}

输出：

Age: 24
  • let：声明变量。
  • age：变量名。
  • 24：变量保存的值。
  • println!：将变量的值输出到终端。

Rust 中变量的声明通常使用 let 关键字。

三、Rust 的变量默认不可变

Rust 与许多其他语言不同，使用 let 声明的变量默认是不可变的（Immutable）。 变量一旦绑定了一个值，就不能直接重新赋予其他值。 

fn main() {
    let score = 100;
    score = 200;

    println!("{}", score);
}

上面的代码会报错，因为 score 默认不可变，不能重新赋值。

Rust 编译器会阻止这种操作。这种设计可以减少意外修改，让程序行为更加可预测。

不可变变量的正确使用

fn main() {
    let score = 100;
    println!("{}", score);
}

输出：

100

如果一个变量的值不需要发生改变，优先使用不可变变量，是 Rust 推荐的编程习惯。

四、使用 mut 声明可变变量

如果希望变量的值能够被修改，需要在声明时使用 mut 关键字。 mut 是 mutable（可变）的缩写。 

fn main() {
    let mut score = 100;
    score = 200;

    println!("{}", score);
}

输出：

200

这里的 score 可以被修改，是因为声明时使用了 mut。

多个修改操作

fn main() {
    let mut score = 0;

    score = 100;
    score = 250;
    score = 500;

    println!("Final score: {}", score);
}

输出：

Final score: 500

变量保存的是当前值。多次赋值后，变量会保存最后一次赋予的值，之前的值不再是该变量的当前值。

let 与 let mut 的区别

声明方式 是否可以重新赋值 说明
let x = 10; 不可以 默认不可变
let mut x = 10; 可以 允许修改变量的值

五、类型推断（Type Inference）

Rust 是一种静态类型语言。每一个变量都有自己的数据类型，编译器需要在编译阶段确定变量的类型。

但大多数情况下，我们不需要手动写出类型。Rust 编译器能够根据变量的值自动推断出类型，这个过程叫做类型推断（Type Inference）。 

fn main() {
    let age = 24;
    let temperature = 36.5;
    let enabled = true;

    println!("{}, {}, {}", age, temperature, enabled);
}

编译器会推断：

变量 值 推断类型
age 24 i32
temperature 36.5 f64
enabled true bool

Rust 的整数默认类型通常是 i32，浮点数默认类型通常是 f64。 布尔值则会被推断为 bool。

六、显式类型标注（Type Annotation）

除了让编译器自动推断类型，我们也可以主动指定变量的类型。 这种写法叫做类型标注（Type Annotation）。 

fn main() {
    let age: i32 = 24;
    let temperature: f64 = 36.5;
    let enabled: bool = true;

    println!("{}, {}, {}", age, temperature, enabled);
}

变量声明的基本格式：

let 变量名: 类型 = 值;

例如：

let level: i32 = 10;
let price: f64 = 19.99;
let is_alive: bool = true;

类型标注可以让代码更明确，也有助于理解程序中每个变量保存的数据。

类型不匹配

Rust 不允许随意将不同类型的数据赋值给同一个变量。 

fn main() {
    let age: i32 = 24;
    age = 25.5;
}

这段代码会报错，因为 age 的类型是 i32，而 25.5 是浮点数，无法直接赋给整数类型变量。

即使使用 mut，也只能修改值，不能改变变量原本的类型。

七、Shadowing（变量遮蔽）

Shadowing 是 Rust 的一个重要特性。我们可以使用新的 let 声明，再次创建一个与之前同名的变量，遮蔽旧变量。 

fn main() {
    let x = 10;
    let x = 20;

    println!("{}", x);
}

输出：

20

第二次声明 x 并不是修改第一次声明的变量，而是创建了一个新的变量。新的变量遮蔽了旧变量，因此后续使用 x 时会访问新变量。

利用 Shadowing 进行计算

fn main() {
    let x = 5;
    let x = x + 1;
    let x = x * 2;

    println!("x = {}", x);
}

输出：

x = 12

计算过程：

  1. 第一次声明：x = 5
  2. 第二次声明：读取旧的 x，计算 5 + 1 = 6，创建新 x
  3. 第三次声明：读取当前的 x，计算 6 × 2 = 12，再次创建新 x

这里能够读取旧变量，是因为新变量的初始化表达式会先计算，计算时仍然可以访问被遮蔽的旧绑定。

Shadowing 可以改变类型

普通的变量重新赋值不能改变类型，但是 Shadowing 可以重新声明同名变量，因此允许改变类型。 

fn main() {
    let data = 100;
    println!("{}", data);

    let data = "100";
    println!("{}", data);

    let data = true;
    println!("{}", data);
}

输出：

100
100
true

这里的 data 依次经历了不同类型：

  • 整数：i32
  • 字符串切片：&str
  • 布尔值：bool

每次新的 let data 都创建了一个新的变量绑定，旧变量被遮蔽。这并不代表 Rust 允许一个变量随意改变类型，而是创建了新的变量。

Shadowing 与 mut 的区别

特性 mut Shadowing
修改值 可以 可以通过新声明实现
改变类型 不可以 可以
是否重新声明 否 是
关键字 let mut 再次使用 let

八、作用域（Scope）

作用域是变量可以被访问的范围。在 Rust 中，使用大括号 {} 可以创建一个代码块（Block），代码块内部声明的变量通常只能在该代码块内部使用。 

fn main() {
    let outside = 100;

    {
        let inside = 200;
        println!("{}", outside);
        println!("{}", inside);
    }

    println!("{}", outside);
}

输出：

100
200
100

内部代码块可以访问外部声明的变量，但是外部代码块不能访问内部声明的变量。

内部变量不能在外部使用

fn main() {
    {
        let number = 100;
    }

    println!("{}", number);
}

这段代码会报错，因为 number 在内部代码块结束后就不再处于可访问的作用域中。

作用域可以帮助组织代码、限制变量的使用范围，并减少变量之间的意外干扰。

九、常量（Constants）

常量是程序中不会发生变化的值。Rust 使用 const 声明常量。 

const MAX_HP: i32 = 100;
const MAX_LEVEL: u32 = 99;
const PI: f64 = 3.1415926;

fn main() {
    println!("{}, {}, {}", MAX_HP, MAX_LEVEL, PI);
}

输出：

100, 99, 3.1415926

常量的特点

  • 使用 const 声明。
  • 必须明确指定类型。
  • 必须在声明时赋予值。
  • 不能使用 mut。
  • 值必须是编译期能够确定的常量表达式。
  • 常量可以声明在函数外部，也可以声明在允许的作用域中。
  • 常量命名通常使用全大写字母和下划线。

常量与变量的区别

对比 变量 常量
声明关键字 let const
默认可变性 默认不可变 始终不可变
允许 mut 允许 不允许
类型标注 可以推断 必须标注
声明时赋值 需要 需要
运行时修改 使用 mut 后可以 不可以

常量命名规范

const MAX_HP: i32 = 100;
const MAX_LEVEL: u32 = 99;
const PI: f64 = 3.1415926;
const DEFAULT_SPEED: f64 = 10.0;

推荐使用 SCREAMING_SNAKE_CASE（全大写下划线命名法）。

十、变量命名规范

Rust 使用不同的命名风格来区分变量、常量、函数等内容。

类型 推荐命名风格 示例
变量 snake_case user_name
函数 snake_case calculate_score
常量 SCREAMING_SNAKE_CASE MAX_VALUE
类型、结构体 PascalCase PlayerData

正确示例

let user_name = "Rust";
let player_score = 100;
let is_alive = true;

const MAX_SCORE: i32 = 1000;

不推荐示例

let UserName = "Rust";
let playerScore = 100;
let isAlive = true;

const maxScore: i32 = 1000;

不规范的命名通常不会导致程序运行失败，但可能产生编译器警告。统一的命名风格能让代码更容易阅读，也符合 Rust 社区习惯。

十一、常见错误与编译器提示

1. 不可变变量重新赋值

let x = 10;
x = 20;

错误原因：变量默认不可变，不能重新赋值。

解决方法：

let mut x = 10;
x = 20;

2. 类型不匹配

let mut x = 10;
x = 3.14;

错误原因：x 是整数类型，不能直接赋值为浮点数。

3. 变量未使用

let x = 100;

如果变量声明后从未被使用，编译器通常会发出未使用变量警告（Warning）。

如果暂时不使用变量，可以在变量名前加下划线：

let _x = 100;

4. 常量命名不规范

const MaxHp: i32 = 100;

可能出现常量命名规范警告。建议改为：

const MAX_HP: i32 = 100;

Warning 与 Error

提示类型 含义
Warning（警告） 代码可能存在不规范或潜在问题，通常仍然可以编译。
Error（错误） 代码存在无法通过编译的问题，必须修复才能成功编译。

Rust 的编译器不仅负责生成程序，也会帮助开发者发现错误、提示风险，并引导代码遵循更安全的习惯。

十四、课程总结

本课学习了 Rust 的变量声明、可变性、类型推断、变量遮蔽、作用域与常量。

  • let：声明变量，默认不可变。
  • let mut：声明可变变量，允许修改值。
  • mut：允许变量重新赋值，但不能改变变量类型。
  • Type Inference：类型推断，编译器根据值自动确定变量类型。
  • : i32、: f64、: bool：显式类型标注。
  • Shadowing：使用新的 let 声明遮蔽已有的同名变量。
  • let x = x + 1;：读取旧变量的值，计算后创建新的同名变量。
  • Shadowing：可以重新声明同名变量，甚至改变其数据类型。
  • {}：代码块，创建独立作用域。
  • Scope：变量的有效范围，内部作用域可以访问外部变量，外部不能访问内部变量。
  • const：声明常量，必须指定类型，值不可修改。
  • SCREAMING_SNAKE_CASE：常量命名规范，例如 MAX_HP、MAX_LEVEL。
  • snake_case：变量与函数命名规范，例如 user_name、player_score。
  • Warning：编译器警告，提示潜在问题或不规范写法。
  • Error：编译错误，代码存在无法通过编译的问题。

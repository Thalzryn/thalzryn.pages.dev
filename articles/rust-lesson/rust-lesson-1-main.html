Rust 第一课：程序入口与格式化输出

一、学习目标

完成本课后，你应该能够：

  • 理解 Rust 程序的基本结构。
  • 理解 fn main() 的作用。
  • 使用 print! 和 println! 输出内容。
  • 使用占位符输出不同的数据。
  • 使用位置参数与命名参数。
  • 控制数字格式、小数位数、补零与对齐方式。
  • 使用转义字符输出特殊内容。
  • 理解常见的格式化输出错误。

二、Rust 程序的基本结构

1. Hello World

Rust 可执行程序通常从 main 函数开始执行。

fn main() {
    println!("Hello, world!");
}

2. 代码结构解析

代码 说明
fn 用于声明函数（function）。
main 程序入口函数名称。
() 函数参数的位置，本例中没有参数。
{} 用于包围函数体，规定代码块的范围。
; 语句结束符。

3. main 函数

main 是普通 Rust 可执行程序的入口函数。 当程序启动时，系统会从 main 开始执行。 

fn main() {
    println!("第一条指令");
    println!("第二条指令");
    println!("第三条指令");
}

程序默认按照代码书写顺序执行，从上到下依次运行。

4. 大括号与代码块

Rust 使用大括号 {} 划定代码块。 函数、条件语句、循环等结构都会使用大括号。 

fn main() {
    // 代码写在这里
}

三、终端输出：print! 与 println!

1. println!

println! 用于向终端输出内容，并在输出结束后自动换行。 

fn main() {
    println!("Hello, Rust!");
    println!("I am learning Rust.");
}

输出结果

Hello, Rust!
I am learning Rust.

2. print!

print! 用于输出内容，但不会自动添加换行。 

fn main() {
    print!("Hello ");
    print!("Rust ");
    print!("World!");
}

输出结果

Hello Rust World!

3. 两者的区别

宏 作用 是否自动换行
print! 输出内容 否
println! 输出内容 是

4. 混合使用

fn main() {
    print!("Hello ");
    print!("Rust ");
    println!("World!");
    println!("Next line.");
}

输出结果

Hello Rust World!
Next line.

前两个 print! 不换行， 第三个 println! 输出完成后换行， 因此最后一句出现在新的一行。

四、格式化输出与占位符

1. 什么是占位符？

占位符用于在字符串中预留位置， 并在输出时将对应的数据填入其中。

最基本的占位符是 {}。

fn main() {
    println!("我今年 {} 岁", 24);
}

输出结果

我今年 24 岁

其中：

  • {} 表示数据填入的位置。
  • 24 是传入的值。
  • Rust 在输出时将数据格式化并填入占位符。

2. 多个占位符

一段字符串中可以包含多个占位符。

fn main() {
    println!("我有 {} 个苹果，{} 个橘子。", 3, 5);
}

输出结果

我有 3 个苹果，5 个橘子。

默认情况下，占位符按从左到右的顺序， 匹配后面提供的参数。

占位符 对应参数 输出
第一个 {} 3 3
第二个 {} 5 5

3. 不同类型的数据

占位符不仅可以输出数字，也可以输出文字。

fn main() {
    println!(
        "姓名：{}，年龄：{}，身高：{} cm",
        "小明", 18, 175
    );
}

输出结果

姓名：小明，年龄：18，身高：175 cm

五、位置占位符

1. 什么是位置参数？

Rust 允许通过参数的索引来指定占位符使用哪个数据， 而不必按照参数的默认顺序输出。

位置索引从 0 开始。

fn main() {
    println!("{1} {0}", "World", "Hello");
}

输出结果

Hello World

2. 参数索引对应关系

索引 参数
0 "World"
1 "Hello"

因此：

  • {0} 输出第 0 个参数。
  • {1} 输出第 1 个参数。

3. 改变输出顺序

fn main() {
    println!("{2}, {0}, {1}!", "world", "Rust", "Hello");
}

输出结果

Hello, world, Rust!

参数顺序不需要改变， 只需改变占位符中的索引即可控制输出顺序。

4. 重复使用同一个参数

同一个位置参数可以被多次引用。

fn main() {
    println!("{0}，欢迎学习 Rust！{0}，加油！", "同学");
}

输出结果

同学，欢迎学习 Rust！同学，加油！

这里两次使用 {0}， 它们都会引用同一个参数。

六、命名占位符

1. 使用名称代替索引

命名占位符允许使用名称引用数据， 使代码更加直观和容易阅读。 

fn main() {
    println!(
        "{name} 今年 {age} 岁",
        name = "小明",
        age = 18
    );
}

输出结果

小明 今年 18 岁

2. 命名参数对应关系

占位符 参数
{name} name = "小明"
{age} age = 18

3. 多个命名参数

fn main() {
    println!(
        "玩家：{player} | 等级：{level} | HP：{hp}",
        player = "Knight",
        level = 20,
        hp = 100
    );
}

输出结果

玩家：Knight | 等级：20 | HP：100
<

4. 命名占位符的优点

  • 可读性更强。
  • 不容易搞错参数对应关系。
  • 适合包含多个参数的格式化字符串。
  • 修改参数排列顺序时，不需要修改占位符名称。

七、数字格式化

1. 控制小数位数

可以通过精度格式指定浮点数输出时保留的小数位数。 

fn main() {
    println!("{:.1}", 3.1415926);
    println!("{:.2}", 3.1415926);
    println!("{:.3}", 3.1415926);
    println!("{:.4}", 3.1415926);
}

输出结果

3.1
3.14
3.142
3.1416
格式 含义
{} 默认格式
{:.1} 保留 1 位小数
{:.2} 保留 2 位小数
{:.3} 保留 3 位小数
{:.4} 保留 4 位小数

输出时会根据指定精度进行舍入。

2. 整数补零

可以指定数字的最小输出宽度， 并使用零填充不足的位数。 

fn main() {
    println!("{:04}", 7);
    println!("{:04}", 42);
    println!("{:04}", 2026);
}

输出结果

0007
0042
2026

{:04} 表示：

  • 输出宽度至少为 4 个字符。
  • 不足 4 位时在前面补零。
  • 达到或超过 4 位时不截断。

3. 数字宽度

可以控制数字输出占据的最小字符宽度。 默认情况下，宽度填充使用空格。 

fn main() {
    println!("{:4}", 85);
    println!("{:4}", 7);
    println!("{:4}", 1234);
}

输出结果

  85
   7
1234

{:4} 表示最小宽度为 4， 默认右对齐，不足时在左侧填充空格。

八、文本对齐

1. 左对齐

fn main() {
    println!("{:<10}|", "Rust");
}

输出效果

Rust      |

{:<10} 表示在宽度为 10 的范围内左对齐。

2. 右对齐

fn main() {
    println!("{:>10}|", "Rust");
}

输出效果

      Rust|

{:>10} 表示宽度为 10，右对齐。

3. 居中对齐

fn main() {
    println!("{:^10}|", "Rust");
}

输出效果

   Rust   |

{:^10} 表示宽度为 10，居中对齐。

4. 对齐方式速查表

格式 含义
{:<10} 左对齐，宽度 10
{:>10} 右对齐，宽度 10
{:^10} 居中对齐，宽度 10

九、转义字符

1. 什么是转义字符？

在字符串中，一些字符具有特殊含义。 转义字符允许我们表示换行、制表符、反斜杠以及引号等内容。

2. 常见转义字符

写法 效果
\n 换行
\t 制表符（Tab）
\\ 输出反斜杠
\" 输出双引号
\' 表示转义单引号（在字符字面量中通常需要）

3. 换行符

fn main() {
    println!("第一行\n第二行\n第三行");
}

输出结果

第一行
第二行
第三行

4. 制表符

fn main() {
    println!("姓名\t年龄");
    println!("小明\t18");
    println!("小红\t20");
}

输出效果

姓名    年龄
小明    18
小红    20

\t 会插入制表符。 实际显示宽度可能因终端和字体而不同。

5. 输出反斜杠

fn main() {
    println!("C:\\Rust\\Project");
}

输出结果

C:\Rust\Project

6. 输出双引号

fn main() {
    println!("他说：\"Hello Rust\"");
}

输出结果

他说："Hello Rust"

十、常见错误

1. 忘记语句结束符

错误示例：

fn main() {
    println!("Hello")
}

正确示例：

fn main() {
    println!("Hello");
}

2. 括号不匹配

错误示例：

fn main() {
    println!("Hello";
}

正确示例：

fn main() {
    println!("Hello");
}

3. 占位符数量不匹配

错误示例：

fn main() {
    println!("{} {}", 10);
}

两个占位符，却只提供了一个参数。

正确示例：

fn main() {
    println!("{} {}", 10, 20);
}

4. 命名占位符名称不匹配

错误示例：

fn main() {
    println!("{name}", username = "Rust");
}

正确示例：

fn main() {
    println!("{username}", username = "Rust");
}

5. 混淆 print! 与 println!

如果需要换行，却使用 print!， 后续输出会接着出现在同一行。 

fn main() {
    print!("Hello");
    println!(" Rust");
    println!("Next line");
}

输出结果

Hello Rust
Next line

十一、综合示例

1. 终端个人介绍

fn main() {
    println!("========================");
    println!("    Rust Student");
    println!("========================");

    println!("Name: {}", "Alex");
    println!("Age: {}", 24);
    println!("Language: {}", "Rust");
    println!("Progress: {:.1}%", 12.5);

    println!("------------------------");
    println!("Hello, Rust!");
    println!("Keep learning!\n");
}

输出结果

========================
    Rust Student
========================
Name: Alex
Age: 24
Language: Rust
Progress: 12.5%
------------------------
Hello, Rust!
Keep learning!

2. 本示例使用的知识

  • 程序入口：fn main()
  • 普通文本输出：println!
  • 占位符：{}
  • 小数格式化：{:.1}
  • 多条语句顺序执行
  • 转义换行：\n

十四、课程总结

本课学习了 Rust 程序的基础结构与终端输出。

  • fn main()：程序入口。
  • println!：输出并换行。
  • print!：输出但不换行。
  • {}：普通占位符。
  • {0}、{1}：位置占位符。
  • {name}：命名占位符。
  • {:.2}：控制小数位数。
  • {:04}：数字补零。
  • {:<10}、{:>10}、{:^10}：对齐格式。
  • \n、\t、\\、\"：转义字符。
